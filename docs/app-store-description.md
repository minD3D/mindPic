# App Store 등록 정보 초안

## 이름 (30자 이내)
mind PIC - 스와이프 사진 정리

## 부제 (30자 이내)
넘기기만 하면 끝나는 사진 정리

## 프로모션 텍스트 (170자 이내, 심사 없이 수정 가능)
쌓여만 가는 사진, 이제 한 장씩 넘기면서 정리하세요. 오른쪽은 좋아요, 왼쪽은 휴지통. 실수해도 바로 실행 취소할 수 있어요.

## 설명 (4,000자 이내)
사진첩에 수천 장이 쌓여 있는데 정리할 엄두가 안 나나요?
mind PIC은 사진을 한 장씩 넘기면서 남길 사진과 지울 사진을 빠르게 고르는 앱입니다.

■ 스와이프 한 번으로 정리
· 오른쪽으로 밀기 — 좋아요 (사진 앱 즐겨찾기에 추가)
· 왼쪽으로 밀기 — 휴지통으로 이동
· 탭 — 보관하고 다음 사진으로
· 실수로 지웠다면 바로 '실행 취소'
· 스와이프가 어색하다면 사진 아래 휴지통 · 보관 · 좋아요 버튼으로
· 홈 화면에서 지금까지 본 사진과 휴지통에 모인 사진 수를 한눈에

■ 오늘은 어떤 사진을 정리할까요?
· 랜덤 100장 — 부담 없이 조금씩
· 랜덤 1개월 — 잊고 있던 한 달을 꺼내 보기
· N년 전 오늘 — 그날의 추억을 다시 보며 정리
· 최근 7일 / 30일 — 쌓이기 전에 바로바로
· 원하는 달 선택
· 스크린샷, 연사, 인물 사진, 즐겨찾기 안 된 사진만 모아 보기
· 안 본 사진만 보기 — 이미 확인한 사진은 건너뛰기

■ 안심하고 지우세요
지운 사진은 곧바로 사라지지 않고 앱의 휴지통에 모입니다.
휴지통에서 다시 확인하고, 필요하면 복원할 수 있어요.
휴지통을 비우면 사진 앱의 '최근 삭제된 항목'으로 이동해 30일 동안 한 번 더 되살릴 수 있습니다.

■ 사진은 내 기기 밖으로 나가지 않아요
· 회원가입, 로그인 없음
· 광고, 분석·추적 도구 없음
· 모든 사진은 기기 안에서만 처리되며 어디에도 전송되지 않습니다

출퇴근길, 잠들기 전 5분. 오늘부터 조금씩 가벼워지는 사진첩을 만나 보세요.

## 앱 심사 정보 메모 (App Review Information)
This app helps users review and clean up their photo library. It requires photo library access ("Full Access" recommended) to function. All processing happens on-device; no data is collected or transmitted.
How to test: Tap "Start Reviewing" ("사진 탐색 시작") → allow photo access → swipe right to favorite, swipe left to move to the in-app trash, tap to keep. Deleting from the in-app trash ("View Trash" → "Empty Trash" / "휴지통 비우기") calls PhotoKit deletion, which shows the system confirmation dialog.
